# Redux Movie Store

A learning project for **Redux** with Next.js and TypeScript. It's a movie list where you can add movies, add them to a basket and like them.

## Features

- A store built with classic Redux: `createStore`, a reducer and action types.
- React Redux wiring in the Next.js App Router (`useSelector`, `useDispatch`).
- Immutable state updates for lists.
- Work in progress: migrating the store to Redux Toolkit.

## Tech stack

Next.js 16 · React 19 · TypeScript · Redux · Redux Toolkit · Tailwind CSS 4
